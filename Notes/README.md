# Our Notes

《BanG Dream! Our Notes》五支乐队的 Livehouse 抢位卡牌游戏。**双击 `index.html` 就能玩**，不用装环境、不用起服务器。

> 这一版是重做的：不再是 Kards 那套「三线 + 主场热度」，
> 改成 **五人乐队常驻阵营 + 抢舞台位置 + 闪耀值赛跑 + 剪影卡加持**。

---

## 开局流程

双击 `index.html` 先看到**主界面**（演唱会灯光 + 「开始游戏」），点下去以后依次弹三步：

1. **请选择乐队** —— 五张乐队海报（五个人物立绘 + 乐队色逆光 + 标语 + 成员名单），选一张；
2. **请选择敌方乐队** —— 从剩下的四支里挑对手（已选的不会再出现）；
3. **请选择难度** —— 简单 / 普通 / 困难，只影响电脑对手（步数、上台欲望、额外资源），你的规则三档完全一样。

选完直接开演，顶栏「第 N 幕」旁边会挂着当前难度的角标。

## 玩法速览

| | |
|---|---|
| **目标** | 闪耀值先到 **50** 的那边赢（`config.js` 可改） |
| **成员** | 每支乐队 5 人，开局全在自己阵营，不会阵亡 |
| **舞台** | 中间那个台子，双方共用，最多站 **5** 人（不预留格子，上台后自适应排开） |
| **星星 ★** | 第 1 回合 1 颗，每回合 +1，涨到 **8** 就停；每回合开始补满 |
| **花费** | 登台/下场花该成员的**费**（队长 3★、其余 2★）；**在舞台上出手对战 2★**、**从自己阵营打台上 3★**；卡牌看卡面左上角 |
| **回合结束** | 台上每 1 人 +1 闪耀；3 人再 +1、4 人再 +2、5 人再 +3（一次最多 +8） |
| **活力值归零** | 退回自己阵营休息 **3** 回合，回来时活力值全满 |

### 怎么操作

- **按住自己的成员拖出去**，会拉出一条金色的**星星箭头流**：
  - 拖到台子上 → 登台（花该成员的费：队长 3★、其余 2★）
  - 拖回自己阵营 → 下场（同上）
  - 拖到敌方成员身上 → 和他对战（台上出手 2★ / 从阵营出手 3★）
- **按住手牌拖出去**：需要目标的卡，拖到目标成员身上松手；不需要目标的卡，**明显往上拖出手牌区**再松手就打出（拖动时卡会跟着指针走，拖到位会变成金框 + 提示「松手打出」）。
- 单击手牌只是看详情，不会误打出。
- `Esc` 取消选择，`空格` 结束回合。

### 对战花费为什么不一样

```
自己阵营  ——3★——→  舞台上的敌人         （要从台下挤上去，贵）
舞台上    ——2★——→  舞台 / 对方阵营的敌人（人就在台上，便宜）
```

所以「先把人推上台，再开打」永远比「站在台下隔空打」划算。

### 距离与射程

```
对方阵营  ←1→  舞台  ←1→  自己阵营
```

攻击距离是 2，所以：

| 你在哪 | 能打到谁 |
|---|---|
| 自己阵营 | 只能打**舞台上的**敌人 |
| 舞台 | 能打**舞台上的**敌人，也能打**对方阵营里**的敌人 |
| —— | 己方成员**永远不能**跑到对方阵营去 |

被打到 0 活力值的成员退到自己的阵营休息，所以「阵营」既是安全的窝，也是被打回来养伤的地方。

**怎么知道能不能打**：拖起成员时，射程内**现在真能打**的敌人会亮起来、打不了的变暗；落点还有 ±26px 的宽容判定（差几个像素也算命中）。真打不了时一定会弹出原因——星星不足 / 本回合已经对战过 / 怯场中 / 禁演中 / 对方回避中 / 台上没有敌人。已经对战过的成员右上角会有金色「战」标记。

### 怯场 = 完全无法行动

`影色舞`（MyGO!!!!!）和 `Imprisoned XII`（Ave Mujica，还附带禁演）打出去以后，目标**下一个回合什么都做不了**：

| 被封住的 | 说明 |
|---|---|
| 移动 | 不能登台、也不能下场 |
| 对战 | 不能攻击，也不会出现在「可打目标」列表里 |
| 闪耀结算 | 就算人还站在台上，也**不计入**回合结束的台上人数（连带 3/4/5 人的额外加成也按少一人算） |

- 生效时机：出牌当下就进入状态，持续到**被怯场那一方自己的回合结束**，也就是整整封住 1 个回合。
- 视觉：成员卡整张压暗、盖一层紫色「怯场 / 无法行动 / 1 回合」遮罩，右上角有「怯场」角标，出牌瞬间飘字 + 战斗日志里也会记一条。
- 解除：自动解除，或提前用带 **净化** 的卡（如 `Angelfire`）解掉。
- 引擎里的判定：`canMove()` / `canAttack()` 直接拦住，`activeStageMembers()` 负责把怯场的人排除在闪耀结算之外；AI 不会指挥怯场的成员行动。

## 人物立绘

每一名成员都有一张立绘，放在 `assets/members/<成员 id>.webp`，比如 `mygo_tomori.webp`（高松燈）。
成员卡、详情面板、选队海报里的五个人，用的都是这些图。

- **每支乐队默认读第一张图**：素材源里每个角色有两张（`名字.webp` 和 `名字_2.webp`），
  现在接的是不带 `_2` 的那张。想换成第二张，直接把 `_2` 那张复制过来覆盖同名文件即可。
- **图太大要压**：原始立绘是 1800×2160，25 张全尺寸解码要占几百 MB 内存，一定会卡。
  现在统一裁掉透明边、缩到 **560px 高**、WebP 质量 82，25 张加起来不到 0.8 MB。
- **缺图不会开天窗**：任何一张读不到，会自动回退成代码画的剪影（发型 × 乐器），
  游戏照常跑，控制台也不会报错。
- 想换成自己的图：文件名对上成员 id、保持透明底、高度 500～600px 就行。

## 结算演出

**闪耀值一到 50 就当场结算**，不用等回合结束（卡牌加闪耀、队长登台 +1 闪耀、回合末结算，任何一条路顶到 50 都立刻触发）：

1. 全场压暗，聚光灯打到赢方身上；
2. 赢方成员逐个亮起（金色描边 + 粒子），中央打出 `★ WINNER ★` + 乐队名 + 最终闪耀值；
3. 约 2 秒后再弹结算面板，大字显示 **优胜**（你赢）或 **惜败**（对手赢）。

结算演出只播一次，结束回合或再点按钮都不会重播。

面板上两个按钮：

| 按钮 | 作用 |
|---|---|
| **返回主菜单** | 收掉高亮/聚光灯/彩带，回到标题页（可以重新选乐队、选难度） |
| **再演一场** | 用同一组乐队和同样的难度直接开下一局 |

两个都是**原地切换**（不刷新页面），所以回到标题页再开一局，人物图、流畅模式、主题设置全都不用重新加载。
顶栏的「重开」也走同一套流程，等于「再演一场」。

## 性能

这一版专门做过一轮瘦身（原来每走一步都全量重建整个棋盘，弱机上明显发顿）：

| 改了什么 | 效果 |
|---|---|
| 立绘裁边 + 缩到 560px 高、转 WebP | 25 张从 3.1 MB / 数百 MB 解码内存 → **0.79 MB** |
| 棋盘改成**增量渲染**（按 uid 复用卡片元素，数值与状态没变就不动 DOM） | 单次 `render()` 在 4 倍降速的机器上 **29.7ms → 1.2ms** |
| 去掉全屏扫描线的 `mix-blend-mode: overlay` | 省掉整屏每帧混合 |
| 去掉剪影的双层 `drop-shadow`、成员卡脚下的 `blur`、台口跑马灯的 `drop-shadow` | 每张卡少 3 处滤镜重绘 |
| 背光呼吸动画只留给**台上**的人（原来 10 张卡都在跑） | 常驻动画少一半 |
| 拖拽时缓存 SVG 路径长度（原来每帧都量一次 + 7 次取点） | 拖拽不再掉帧 |

另外顶栏有 **「流畅」** 开关（`&perf=1` 直接开）：关掉桁架灯、扫射光束、观众荧光棒、台口跑马灯这些纯装饰层，
只留人物和卡牌。第一次进游戏会量 1.2 秒帧率，低于 46 fps 会自动帮你打开（手动改过就以你的为准，记在 localStorage）。
拖拽的瞬间氛围动画也会自动暂停，把帧让给箭头和卡影。

## 手机端（竖屏）

手机浏览器打开即玩，**以竖屏为正式体验**（不再引导横屏；横屏只是兜底，不专门维护）。

适配要点：

| 项目 | 做法 |
|---|---|
| 视口 / 安全区 | `viewport-fit=cover` + `100dvh`，避开手机地址栏伸缩与刘海；手牌区底部留 `safe-area-inset-bottom` |
| 顶栏 | 两个对阵面板一行，回合信息 / 难度 / 按钮换到第二行，不再把标题挤成竖排 |
| 侧栏 | 默认隐藏，顶栏多一个 **「详情」** 按钮，从右侧滑出抽屉；一碰棋盘或手牌就自动收起 |
| 阵营 5 张卡 | 星星盘压到 50px 宽、卡高按 `vh` 收放，5 张卡 + 星星盘稳定挤进一行（390px 宽实测 390/390，无横向滚动） |
| 成员卡 | 名字单行、藏掉代号，`♪ 3` 与 `5/5` 各占一行，费用与队长角标缩小，避免压字 |
| 手牌 | 横向滑动浏览（`overflow-x: auto`），卡片放大到 96~122px 高，卡名与效果文字可读 |
| 触屏手势 | 成员 / 卡牌 `touch-action: none`（拖拽不会被当成滚动），手牌 `pan-x`（横滑翻牌、上拖打出），并关掉下拉刷新与长按菜单 |
| 弹窗 | `max-height: 92dvh` 可滚动，选乐队海报自动换列，按钮加大到便于点按 |

宽屏（>900px）完全不加载这套规则，桌面观感不变。

## ★ 改数值

### 成员数值（等你的设定）

`src/bands.js` 里 25 条，改这两个字段就行，引擎/UI/AI 全部自动读：

```js
{ id: "mygo_tomori", leader: true, name: "高松 燈", band: "MYGO", role: "vo",
  cost: 3,    // ← 费（登台/下场花这颗数）
  skill: 3,   // ← 技能值（攻击力）
  vita: 5,    // ← 活力值（生命值）
  line: "……我想，把这份心情唱出来。" }
```

| 字段 | 说明 |
|---|---|
| `leader` | 是否队长：登台时额外 +1 闪耀值 |
| `cost` | 费：登台/下场要花的星星 |
| `skill` | 技能值，一次对战打出的伤害 |
| `vita` | 活力值上限，归零就退场休息 |
| `inst` | 剪影手上的乐器：`mic` `guitar` `bass` `drums` `keyboard` `dj` |
| `hair` | 剪影发型：`short` `bob` `long` `ponytail` `twin` `curly` `spiky` |
| `line` | 详情面板里的一句台词，纯装饰 |

### 卡牌数值

`src/cards.js` 里每张卡一条，加卡只要往数组里追加，引擎 / UI / AI 都不用改。

可选的 `copies` 字段：**每方牌库固定放几张**（例如「谢幕」写 `copies: 2`）。
不写就按 `MAX_COPIES`（3 张）随机洗入。

平衡上的两条硬线（改坏了 `tools/selftest.js` 会报警）：

| 约束 | 值 | 原因 |
|---|---|---|
| 单卡**回复量**上限 | **3** | 全员活力值只有 5，回 5 / 6 等于一卡满血复活，能把对面一轮的伤害全抹掉 |
| **群体伤害**（对台上所有敌人）最低费用 | **4★**（现在实际就是 4★） | 一人挨 2 点已经很痛，2～3 人同时挨就是 4～6 点的总伤害 |
| **复活**（让休息中的人立刻回场）最低费用 | **3★**（现在实际是 4★） | 直接省掉 3 回合休息，还是满血回来 |
| 卡牌费用上限 | **不高于星星上限 8★** | 再贵就一辈子打不出 |

按这个表，这几张做过调整：

| 卡 | 调整前 | 调整后 |
|---|---|---|
| 詩超絆（回复 + 再行动 → 回复 + 回避） | 3★ / 回复 6 | **5★ / 回复 3 + 回避** |
| Angelfire（回复 + 净化） | 2★ / 回复 5 | **3★ / 回复 3** |
| 両手いっぱいの幸せ、再来一首！ | 2★ / 回复 5 | **3★ / 回复 3** |
| マイ・ファミリー（回复 + 技能 +1） | 2★ / 回复 4 | **3★ / 回复 3** |
| 壊れた世界の秒針は、Masquerade Rhapsody、烟花特效 | 3★ 群体 2 | **4★** 群体 2 |
| Homie's Tie!!（群体 2 + 抽 1） | 3★ | **4★** |
| 后台休息室（复活） | 2★ | **4★** |
| 夢は無限大（复活） | 3★ / 复活 + 回复 3 | **5★ / 复活 + 技能 +2** |

第二轮又整体调过一次：**除三张产星卡外，所有卡费用 +1**（星星上限从 10 降到 8，经济收紧，卡不能再那么便宜）。

| 卡 | 现在 |
|---|---|
| 物贩区（1★ → 获得 2★） | **1★**（不涨） |
| 一家団欒（1★ → 2★ + 抽 1） | **1★**（不涨） |

> 换成了「技能值 +2」，4★ 才有意义。想改回去把 `fx` 换成 `[{ op: "wake" }, { op: "heal", amount: 3 }]` 即可。

### 谢幕（6★ 强制清场）

| 项目 | 值 |
|---|---|
| 费用 | **6★**（现存最贵的卡，星星上限 8★ 打得出来） |
| 份数 | **每方牌库固定 2 张**（`copies: 2`，不参与随机洗入） |
| 目标 | 不需要选目标 |
| 效果 | **强制**让舞台上双方所有成员下台，各自退回自己的阵营 |

- 「强制」= 无视禁演 / 怯场 / 本回合已移动 / 移动次数，一律请下台；
  休息中的人和本来就在阵营里的人不受影响。
- 不造成伤害、不直接加闪耀，纯粹清空台面。因为回合结束的闪耀是按**台上人数**算的，
  在对手马上要结算时打出，等于把他这回合攒的人数直接抹掉。
- 打出时 UI 会降下一层幕布、每张卡飞回阵营，并飘出「谢幕 · 全员退场」。

### 难度

`src/config.js` 的 `BD.DIFFICULTY`（`budget` = 每回合最多走几步，`stageGoal` = 想把几个人推上台，
`campChase` = 会不会追击阵营里的敌人，`aiStarBonus` / `aiDrawBonus` = 电脑每回合额外的星星与抽牌，
`focusLeader` = 会不会优先集火对方的队长）：

| 难度 | 步数 | 上台目标 | 追击阵营 | 额外 ★ | 额外抽牌 | 集火队长 |
|---|---|---|---|---|---|---|
| 简单 | 2 | 3 人 | 否 | — | — | 否 |
| 普通 | 4 | 4 人 | 是 | — | — | 否 |
| 困难 | **8** | 5 人 | 是 | **+1 ★** | **+1 张** | **是** |

玩家的规则（花费 / 射程 / 结算 / 星星上限）三档完全一样，只有电脑那一侧会多拿资源。

电脑的上台策略（三档都一样，只是目标人数不同）：

- **台上人不够时先上台、再对战**——闪耀值是唯一的胜负手，而且舞台 5 个位置双方共用，
  自己多占一个，对手就少一个能上台抢闪耀的名额；
- 被打退场或被「谢幕」清场后，下一回合会马上补人；
- 星星还有富余时，会继续上台把舞台占满（不受上台目标限制）。

调整后台账镜像 AI 对战平均约 28~32 幕分出胜负（调整前 45+ 幕），
回合结束时平均台上 2 人以上——上台更勤，闪耀值涨得更快。

## 已知简化

1. **没有反击**：对战是单向伤害，被打的一方不还手（想让「对战」互相掉血，在 `engine.js` 的 `attack()` 末尾补一次 `damage` 即可）。
2. **没有连锁/响应窗口**，卡牌打出去立刻结算。
3. 人物立绘取自 `assets/members`，读不到时会退回代码生成的剪影（发型 × 乐器），只靠轮廓和乐队色区分。
4. 卡池是自制版本，按角色定位和代表曲目命名，数值为单机对战调过。
